# Code of Conduct

## Our standard

Creative AI welcomes contributors of different backgrounds and experience levels. Be respectful, constructive, and focused on improving the project.

Examples of positive participation include:

- giving useful, specific feedback;
- discussing technical disagreements without personal attacks;
- helping newcomers understand the contribution process;
- crediting other people's work and ideas;
- respecting privacy and boundaries.

Unacceptable behavior includes harassment, discrimination, threats, deliberate intimidation, doxxing, sexualized or insulting comments, spam, and repeated disruptive behavior.

## Project spaces

This code applies to repository issues, pull requests, reviews, discussions, and other spaces used to represent or maintain Creative AI.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates this code and may restrict participation when necessary to protect the community and project.

If you need to report conduct concerns, contact the maintainer privately through GitHub rather than posting sensitive personal details publicly.

Maintainers should handle reports in good faith, limit unnecessary disclosure, and apply proportionate action based on context and severity.
