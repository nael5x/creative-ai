# Contributor Tasks

Looking for a first contribution? Start with an open issue labeled [`good first issue`](https://github.com/nael5x/creative-ai/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).

Please comment on the issue before starting if you want to claim it, keep the pull request focused, and run the documented test command before submitting.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the full contribution workflow.
