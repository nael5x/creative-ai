# Third-party component and asset notes

- **React Bits Antigravity and BorderGlow:** fetched locally from the [official React Bits registry](https://reactbits.dev/get-started/installation). React Bits uses an MIT + Commons Clause license. It permits use in an application but prohibits redistributing the components themselves. The fetched source files are ignored by Git and are not included in this public branch.
- **Aceternity UI Timeline and Bento Grid:** fetched locally from the [official component registry](https://ui.aceternity.com/docs/cli). Aceternity lists these as free components for React projects. The source files are ignored by Git and are not included in this public branch.
- **MiniDev UI Footer Nav and Link:** copied from [MiniDev UI's official registry](https://ui.minidev.pro/docs/footer-nav). MiniDev states its component library is MIT licensed. The original component structure is retained; the Vite utility import path and local semantic CSS tokens are adapted for this bench.
- **shadcn/ui Button:** added using the official [shadcn CLI](https://ui.shadcn.com/docs/cli) and registry. Generated source remains in the project.
- **Lucide React:** UI icons come from `lucide-react`; Lucide is released under the ISC License. See the [Lucide license](https://github.com/lucide-icons/lucide/blob/main/LICENSE).
- **Lobe Icons OpenAI logo:** loaded from `@lobehub/icons-static-svg` version 1.103.0. Lobe Icons is MIT licensed. See the [Lobe Icons license](https://github.com/lobehub/lobe-icons/blob/master/LICENSE).
