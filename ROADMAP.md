# Roadmap

Creative AI is being developed in small, reviewable milestones.

## Near term

- Externalize the curated tool catalog into `data/tools.json`.
- Add regression tests for Atom and RSS parsing.
- Add source-health reporting for monitored feeds.
- Establish the first tagged release.

## Later

- Expand contributor-friendly validation and documentation.
- Improve source reliability signals.
- Grow the curated directory through verified community contributions.
- Track release notes and maintenance history through GitHub Releases.

The roadmap is directional rather than a promise of dates. Concrete work should be discussed in GitHub issues before implementation.
