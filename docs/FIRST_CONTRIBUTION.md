# First contribution

Creative AI welcomes small, focused pull requests.

A good place to start is the open [`good first issue`](https://github.com/nael5x/creative-ai/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) queue.

Before starting:

1. Read [`CONTRIBUTING.md`](../CONTRIBUTING.md).
2. Comment on the issue you want to work on.
3. Keep the change scoped to that issue.
4. Run the documented validation/tests locally.
5. Open a pull request and describe what changed and how you verified it.

Maintainers will review the change and may request follow-up edits before merging.
