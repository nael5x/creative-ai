# Source policy

Creative AI prefers first-party and project-owned sources for monitored releases and factual product links.

## Preferred

- Official project release feeds
- Official documentation or product pages
- Project-owned GitHub release feeds

## Discovery-only

Discovery platforms can be used to surface candidates, but important claims should be verified against the original project or product source before being presented as authoritative.

## Review principle

A source should provide clear user value, be reasonably stable to parse, and make it possible to trace important information back to an original publisher.
