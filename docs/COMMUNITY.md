# Community

Creative AI welcomes focused contributions that improve factual accuracy, source reliability, bilingual usability, testing, and maintainability.

The healthiest contribution path is:

1. Find or open a concrete issue.
2. Discuss larger changes before implementation.
3. Submit a small pull request with verification notes.
4. Respond to review feedback on the same branch.
5. Keep claims traceable to original sources.

Contribution volume is less important than useful, reviewable work.
