# Localization

Creative AI currently supports English and Arabic.

When changing user-facing copy:

- check whether the equivalent concept exists in both languages;
- prefer natural phrasing over literal translation;
- preserve right-to-left behavior for Arabic;
- avoid changing technical product names unless a familiar Arabic rendering is already used by the project;
- verify search terms remain useful across both language modes.

Translation-only improvements can be proposed through the dedicated issue template.
