# Pull request review

A maintainer review should focus on correctness, scope, verification, and maintainability.

- Confirm the change solves the stated issue.
- Check external links and factual claims against original sources.
- Verify relevant automated checks and local testing notes.
- Request tests for behavior that could regress silently.
- Avoid approving unrelated changes bundled into the same pull request.
- Prefer actionable review comments and explain why a change is requested.
