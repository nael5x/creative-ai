# Releasing Creative AI

The project will use GitHub Releases for meaningful public milestones.

Before a release:

1. Confirm relevant issues are closed or explicitly deferred.
2. Confirm validation workflows pass.
3. Update `CHANGELOG.md` from the `Unreleased` section.
4. Verify the public site still loads the curated catalog and update feed.
5. Tag a clear semantic version such as `v0.1.0`.
6. Write concise release notes describing user-visible and maintainer-facing changes.
