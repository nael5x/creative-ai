# Versioning

Creative AI will use simple semantic version tags for public milestones.

- `v0.x.y` while the project is evolving quickly and contributor workflows are still stabilizing.
- Patch increments for compatible fixes and documentation/maintenance improvements.
- Minor increments for meaningful new capabilities or contributor-facing changes.
- A future `v1.0.0` should represent a stable public contract for the site's data and maintenance workflow.
