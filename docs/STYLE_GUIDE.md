# Content style guide

Creative AI descriptions should be practical, concise, and verifiable.

- Describe what a tool is useful for rather than repeating marketing slogans.
- Avoid unsupported claims such as “best,” “most powerful,” or guaranteed outcomes.
- Prefer short sentences that translate naturally between English and Arabic.
- Link to official destinations.
- Keep availability labels factual and easy to review.
- When a source is discovery-only, say so clearly.
