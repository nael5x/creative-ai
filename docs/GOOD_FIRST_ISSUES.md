# Good first issues

Beginner-friendly issues should be small, well-scoped, and independently verifiable. Good examples for Creative AI include:

- correcting one inaccurate tool description;
- adding one verified tool record to `data/tools.json`;
- improving one Arabic/English translation;
- adding a focused parser regression case;
- fixing one accessibility problem with clear reproduction steps.

Avoid labeling large architectural refactors as beginner tasks.
