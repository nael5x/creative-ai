# Issue triage

Maintainers should classify incoming issues by type, reproducibility, and user impact.

1. Confirm the issue is in scope for Creative AI.
2. Ask for reproduction details or source links when evidence is incomplete.
3. Close clear duplicates while linking the canonical issue.
4. Prefer small implementation issues with explicit acceptance criteria.
5. Keep security-sensitive information out of public threads.
6. Link merged pull requests back to the issue they resolve.
