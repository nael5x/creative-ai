# Maintenance

The project separates maintenance into three areas:

- **Curated directory:** review `data/tools.json` changes for factual wording, official links, duplicates, and valid structure.
- **Source monitor:** review feed failures, parser behavior, and generated `data/updates.json` output.
- **Public UI:** preserve accessibility, bilingual behavior, search, filtering, and responsive layout.

Issues should be triaged by reproducibility and user impact. Prefer focused pull requests linked to a concrete issue, and use GitHub Releases to record meaningful milestones.
