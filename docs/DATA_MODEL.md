# Data model

## Curated tools

`data/tools.json` is maintained by contributors and reviewed through pull requests. Each record contains six ordered string fields documented in `data/TOOLS_FORMAT.md`.

## Monitored updates

`data/updates.json` is generated by `scripts/collect_updates.py`. Each update records an identifier, title, URL, publication timestamp, source, category/kind, purpose, and a short explanation of why it may matter.

Curated data should be edited directly and validated. Generated update data should normally be changed by updating the collector rather than by hand.
